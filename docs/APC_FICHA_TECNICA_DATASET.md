# Ficha técnica para comprovação de APC — geração de dataset público

**Uso:** material de apoio para análise da Coordenação de Atividades Complementares (CAC). Não garante deferimento ou pontuação. A ficha foi atualizada para a edição pública corrigida v1.0.3, publicada no Zenodo. O deferimento e a pontuação dependem da análise da CAC.

## Atividade proposta
- **Atividade:** coleta e/ou análise de dados com geração de dataset de acesso público (item 129/e no barema consultado anteriormente).
- **Produto:** `Tabebuia roseoalba Leaf Area Image Dataset with ImageJ References`.
- **Autores:** Tatiane Morais Neves e Felipe Soares Barbosa, IFMG Campus Bambuí.
- **Conteúdo da edição corrigida:** 198 JPEGs; 181 grupos; 177 grupos com referência ImageJ válida; 191 fotos elegíveis; split por grupo 44 development / 133 final_test.
- **Estado:** edição v1.0.3 publicada com DOI [10.5281/zenodo.24122476](https://doi.org/10.5281/zenodo.24122476); branch `main` do GitHub contém 198 JPEGs da edição atual. A remoção dessas sete imagens do estado corrente **não** apaga commits ou objetos LFS históricos.
- **Data apresentada no campo de publicação do Zenodo:** 22/10/2026 (conforme relatório do responsável; é o valor do metadado, não prova isolada da data efetiva em que a ação Publish foi executada).
- **Confirmação de publicação comunicada pelo responsável:** 11/11/2026.

## Texto de referência do barema
O regulamento APC do curso de Engenharia de Computação do IFMG Campus Bambuí encontrado no site institucional inclui a atividade “coleta e/ou análise de dados com geração de dataset de acesso público” entre as atividades complementares. O PDF disponibilizado é uma referência oficial, porém sua vigência na data do pedido, pontuação, necessidade de DOI/release e documentação exigida devem ser confirmadas diretamente com a CAC. [Regulamento APC hospedado pelo IFMG Campus Bambuí](https://www.bambui.ifmg.edu.br/portal/images/CURSOS/BIBENGC/Atividades_Pr%C3%A1ticas_e_Complementares/Regulamento_APC_EngComp.pdf).

## Observações para a CAC
O total histórico de 205 imagens refere-se à coleção v1.0.2 anterior; a edição corrigida proposta contém 198. A redução remove sete fotos documentais não amostrais e não altera resultados quantitativos. A edição corrigida está pública no GitHub (estado corrente) e no Zenodo; objetos históricos Git/LFS podem permanecer acessíveis. O DOI já foi publicado, mas não implica aprovação automática de APC. Evitar confundir a data registrada no metadado do Zenodo com a data efetiva de disponibilização.
